1Set up your household

Chat with the setup assistant about who's in your household, allergies, cuisines you like, kitchen equipment, preferred stores, and your grocery budget. It saves details as you go — you don't need to answer everything at once.

This step calls Gemini and needs GEMINI_API_KEY set on the server (see README — it's a free key, no credit card). If it's not set, use "Use existing demo household" below instead.
